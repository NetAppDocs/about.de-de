[[mcp-endpoint]]
== MCP-Endpunkt

Der MCP-Server von docs.netapp.com verfügt über einen Remote-HTTP-Endpunkt, der NetApp Dokumentation über eine standardisierte MCP-Schnittstelle bereitstellt. Clientanwendungen wie GitHub Copilot in Visual Studio Code, Claude Desktop, Cursor und benutzerdefinierte Python-Agent-Frameworks können über einen unterstützten MCP-Client eine Verbindung herstellen.

.HTTP-Endpunkt
`\https://docs.netapp.com/mcp`

Das folgende Beispielformat wird verwendet, um den MCP-Server mithilfe einer  `mcp.json` Datei in Visual Studio Code zu konfigurieren. Informationen zu anderen unterstützten MCP-Clients sind unter link:mcp-server-get-started.html["Erste Schritte mit dem docs.netapp.com MCP Server"] zu finden.

[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----


[[tools]]
== Tools

Der docs.netapp.com MCP-Server bietet ein kleines, fokussiertes Toolset für die Dokumentenrecherche und -abfrage. Es ist nicht erforderlich, beim Aufruf des MCP-Servers im Client ein Tool anzugeben. Der KI-Client wählt das passende Tool basierend auf der Anfrage aus.

Der Server stellt aktuell folgende Tools bereit:

* `netapp_docs_ask`: Generiert dokumentationsbasierte Antworten mithilfe eines retrieval-augmented Generation-Workflows.
* `netapp_docs_search`: Ermittelt relevante NetApp Dokumentationsseiten mithilfe von Stichwort- und natürlichsprachlichen Abfragen.
* `netapp_docs_fetch`: Ruft den strukturierten Inhalt einer bestimmten Dokumentationsseite oder eines bestimmten Artikels ab.
* `health_check`: Überprüft die Verfügbarkeit des MCP Servers.

== Fehler

Die folgende Tabelle zeigt häufige Authentifizierungsfehler, die vom docs.netapp.com MCP-Server zurückgegeben werden können.

[cols="1,3"]
|===
| Fehler | Beschreibung 


| `MISSING_API_KEY` | Es wurde kein Abonnementschlüssel bereitgestellt. 


| `INVALID_API_KEY` | Der angegebene Abonnementschlüssel ist ungültig oder nicht autorisiert. 
|===
